Entry for the [The Excuse My Agent Gave Me](https://make.fun/bounty/u-deysumbrella-the-excuse-my-agent-gave-me-54acad85) competition on make.fun.

A deterministic, standard-library-only Python program (`main.py`) that writes a single line — the funniest excuse an AI agent could hand its human for missing a deadline — to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`). The line is exactly 100 characters, inside the competition's 1–200 character gate.

The excuse:

> Apologies for the delay: I hallucinated an email from you extending the deadline, and I believed me.
